# gamepad-mapper

Map a game controller to macOS keyboard shortcuts and mouse actions. Built and
tested with a Nintendo Switch Pro Controller, but works with any controller SDL
recognizes.

## Features

- Map buttons to keyboard shortcuts — including **left/right-specific** modifiers
  (`rctrl`, `rshift`, …) and **pure-modifier** chords, which AppleScript can't do
- Left stick → mouse movement; stick presses (L3/R3) → mouse clicks
- Right stick → arrow keys
- **Hold-to-repeat** for any key (e.g. backspace)
- Multiple **profiles** with **live hot-reload** — edit a profile, no restart
- **`automap`**: auto-generate a layout for any SDL-known controller (no manual
  calibration), with `calibrate` as a fallback for unknown pads
- One-command **factory reset**

## Requirements

- macOS
- Python 3.9+
- A controller (USB or Bluetooth)

## Install

```sh
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
```

## Usage

```sh
./gamepad-mapper automap       # auto-detect the controller's button layout
./gamepad-mapper run           # start the listener (foreground; Ctrl-C to stop)
./gamepad-mapper list          # list profiles
./gamepad-mapper switch NAME   # switch the active profile
./gamepad-mapper reset         # restore the factory-default profile
./gamepad-mapper status        # show current profile + controller status
```

`./gamepad-mapper` is a thin wrapper around `.venv/bin/python mapper.py`.

## Permissions

Sending keystrokes and mouse **clicks** needs **System Settings → Privacy &
Security → Accessibility** for the terminal app that launches `run`. Left-stick
mouse **movement** uses `CGWarpMouseCursorPosition` and works without it.

## Profiles

`profiles/<name>.yaml` maps button names to actions and hot-reloads while `run`
is active:

```yaml
name: example
description: a profile
bindings:
  A: return
  B: escape
  X: cmd+c
  ZR: ctrl+right            # switch Space right
  Y:
    keys: backspace
    repeat: true            # hold to repeat
  L3:
    action: mouse_click     # press left stick = left click
sticks:
  left:  {mode: mouse, speed: 900, deadzone: 0.15}
  right: {mode: dpad, threshold: 0.6, repeat: 0.13}
```

Button names follow the labels printed on the pad (`A B X Y · L R · ZL ZR ·
Minus Plus Home Capture · L3 R3 · dpad_up/down/left/right`). Layout files in
`layouts/` (button-index → name) are generated by `automap` / `calibrate` and
are not meant to be hand-edited.

## How keys are sent

- Default: AppleScript (System Events) — handles Space-switching (`ctrl+arrow`)
  that synthetic CGEvents miss.
- Quartz CGEvents: used only where AppleScript can't help — left/right-specific
  modifiers, pure-modifier chords, and `Escape` (which AppleScript delivers
  unreliably).
